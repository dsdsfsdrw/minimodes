Результат

    Как это работает

    • Движок строит банк из всех регулярных шаблонов (решётки ТВЭЛ с шагом 2–3, графит между топливом, СУЗ регулярной сеткой, сплошное кольцо отражателей) — обычно 500–1300 штук.
    • Каждый шаблон честно симулируется; у каждого живого сразу проверяется гашение СУЗ — негасимый шаблон не может стать победителем.
    • Настройка «шаблонов на перебор» задаёт первую волну; дальше движок перебирает остаток банка и доводит финалиста точечным подбором заливки зазоров — пока не выйдет лимит времени. Всё выделенное время используется.
    • Если ни один шаблон не гасится — включается эскалация: уплотнённые сетки СУЗ в зазорах решётки.
    • Порты воды/пара — ровно одна пара снаружи, вплотную к отражателям; борных поглотителей внутри зоны нет.

    Активная зона

    Порты воды/пара стоят снаружи, вплотную к отражателям (в игре подключаются к любой колонне РБМК снаружи). Барабан-сепаратор — над центром активной зоны. Колонка источника нейтронов обведена зелёным контуром.

    Инструмент

    ЛКМ — поставить колонну, ПКМ — стереть (пустышка). Колёсико не трогает схему.

    Как пустить реактор

    • Источник нейтронов. Генератор выделяет отдельную колонку-источник (Po-Be) ближе к центру зоны — на схеме она обведена зелёным контуром. Держите её при пуске около секунды; когда цепь стала самоподдерживающейся, канал можно заменить обычным ТВЭЛ. Без источника вставьте любой (Po-Be, Ra-Be) в канал ТВЭЛ на ~1 секунду и выньте.
    • Калибровка СУЗ. Перед пуском выставьте ручные стержни на уровень из отчёта генератора (доля извлечения). Автостержни (АР) требуют калибровки — движок подбирает и стартовый уровень, и авто-цель по температуре; в игре они держат режим сами.
    • Консоль РБМК. Ручными регуляторами (РР) удобно управлять прямо с консоли: движок по умолчанию ставит именно их. АР — опция для ленивых.
    • Замедлители. Быстрые нейтроны от деления надо замедлять до тепловых — графит ставится только между топливными колоннами, на путях лучей. Замедлитель между отражателем и топливом бесполезен.
    • Отражатели. Возвращают нейтроны в зону — топливо «пасует» нейтроны друг другу, и реакция живёт вечно (до выгорания). Обод должен быть сплошным: дыры = утечка радиации.
    • Контур. В ReaSim котлам нужна вода (порт входа) и отбор пара (порт выхода). Порты ставятся СНАРУЗИ зоны, вплотную к отражателям — они подключаются к любой колонне РБМК снаружи и не занимают полезных клеток. В обычном режиме котлы работают и без портов.

    Про офлайн-версию

    • Весь движок (симулятор + генератор со структурным перебором) — внутри этого файла, на JavaScript в фоновом потоке. Ни интернета, ни установки, ни докачек: открыли файл — работает.
    • Работает в Chrome, Edge, Firefox, Opera, Safari (современных). Просто откройте файл двойным кликом.
    • Схемы сохраняются в JSON — совместимы с веб-версией калькулятора.
    • C++-версия на сервере быстрее раза в 3–5; JS-порт повторяет её алгоритм точно, просто дольше думает. Понижайте бюджет, если ждёте долго.

    Горячие действия

    • ЛКМ по сетке — поставить колонну, ПКМ — стереть.
    • Кнопка «Стоп» на генераторе мгновенно убивает поиск.
    • «Прогнать 400 тиков» на вкладке «Отчёт» — длинный контрольный прогон текущей схемы.
